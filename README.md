# Lynds Wallpapers
**Fondos de pantalla hechos por LYNDS Project y la comunidad.**

Puedes utilizarlos, distribuirlos, modificarlos y todo siempre y cuando des créditos al autor original (lo puedes ver en el archivo LICENSE).
No puedes subir un archivo sin una licencia libre como CC-BY o CC-BY-SA, ya que Lynds Wallpapers es completamente libre y sin preocupaciones.

> También puedes subir fondos de pantalla con la licencia CC0, pero eso hará que sea de dominio público y no tengas créditos.

¿Qué significa cada licencia?
```
CC-BY: haz lo que quieras, pero dame créditos.
CC-BY-SA: haz lo que quieras, pero dame créditos y utiliza la misma licencia permisiva.
CC0: no es mio ni es de nadie, es de todos (dominio público).
```
